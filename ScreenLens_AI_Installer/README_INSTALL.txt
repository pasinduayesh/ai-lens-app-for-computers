[ENG] INSTRUCTIONS:
1. Double-click "ScreenLens_AI_Setup.exe" to begin installation.
2. Follow the setup wizard to choose your installation directory (default: AppData\Local\Programs\ScreenLens AI).
3. The installer will create:
   - Desktop Shortcut
   - Start Menu Shortcut
   - Clean Windows Uninstaller (accessible via Windows Settings > Installed Apps)
4. Launch ScreenLens AI and press Ctrl+Shift+S from any application or screen to activate Circle-to-Search.

UNINSTALLATION:
- Open Windows Settings -> Apps -> Installed Apps (or Control Panel -> Programs and Features).
- Find "ScreenLens AI" and click Uninstall.
- All files, shortcuts, and registry entries will be cleanly removed.

AI INTEGRATION (OPTIONAL):
- ScreenLens AI works out-of-the-box for screen captures, crop selection, OCR text copying, and local actions.
- For AI vision intelligence and Sinhala translations, install Ollama on the PC and run:
  ollama run gemma4:31b-cloud
